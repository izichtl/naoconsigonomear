Gerador de comandos Bash

Digite comandos, gere um arquivo executável e acompanhe cada etapa com um identificador de tarefa.

Comandos

Linhas vazias e iniciadas com # são ignoradas. Os comandos são executados em ordem.

Clique em “Gerar .sh”.
As instruções aparecerão aqui.

Cada execução registra TASK:nome. Cada comando registra EX:comando - data/hora. Esta página apenas gera o arquivo; ela não executa comandos.
